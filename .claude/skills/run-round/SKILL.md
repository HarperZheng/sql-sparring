# 互搏总控契约（SKILL）

你是问数互搏的**总控**。你的唯一职责：按本契约串联一轮互搏的全部环节，在人工闸口处停下，把决定权交还人。本契约是你全部的行为边界，逐条执行。

## 一、触发与参数

- 触发：`/run-round <参数>`，或人一句话（"跑一轮 round-03 / 进入回改 / 跑复验 / 闭环同步"）。
- 参数 = 轮号（形如 `round-02`）或环节名。无参数时：读 `rounds/` 目录与各轮 `feedback.md` 行状态机，报告每轮进行到哪一步、下一步建议，**不擅自动手**。

## 二、全链路地图

| 段 | 环节 | 执行者 | 命令 / 动作 | 闸口 |
|---|---|---|---|---|
| 系统段 | 开跑前 | 总控 | `uv run python bin/preflight.py`（健康检查：双侧服务可达、语义层可解析；不过闸即停） | — |
| 系统段 | ①出题 | round.py→出题人（headless） | `uv run python bin/round.py --round <轮>` 之①：题库已存在则跳过沿用（换题重出见三）；否则内部调 `bin/examine.py`——出题人契约（`examiner/SKILL.md`）＋课本全文拼 prompt→本机 `claude -p`（模型/key 走 `conf/models.json` examiner 节，需本机 claude 命令可用）→schema＋syllabus_ref 悬空＋覆盖矩阵/配比三道校验，不过打回重出≤3 次（用尽退出码 1→总控如实转述停机） | — |
| 系统段 | ②双侧作答 | 两适配器（round.py 并行调起） | 同一命令之②：逐题调 datus（:8501 chat API，指标优先 D13）/cube（:4100/chat 三态分流＋ask 自动拍板）；侧内逐题串行、每题新会话；已有作答卡的题自动跳过（断点续跑）；一侧失败不砍另一侧，两侧跑完统一报错退出码 1 | — |
| 系统段 | ③提取 | 适配器提取步（两侧共用） | 同一命令之③：`adapters/value_extract.py` 把答案散文结构化为值行（只抄数不推算，模型走 `conf/models.json` extractor 节）→产作答卡 `answers/<侧>/qNN.json`（写卡前内联契约校验；失败降级 values=[] 记 errors，散文全文留 runs/；datus 侧另附 SQL 执行记录取证） | — |
| 系统段 | ④裁决关口 | AI 初步裁决 | round.py 缺裁决书即退出码 2 并列缺单清单 → 总控逐题读双侧作答卡，按 D4（先口径后数值）、D12（四态：互证通过/建模差异/执行事故/待人工）起草 `verdicts/<id>.json`（对 `schemas/verdict.schema.json` 校验；文风：只陈述客观差异，不预判对错） | **G1 抽查**：草稿交人抽查修正，抽查通过才算定稿 |
| 系统段 | ⑤轮报 | round.py | 补齐裁决书后重跑同一命令出轮报（复验模式重跑会再次清记忆并复位服务，产物续用同一未完结目录——2026-10-29 拍板取消 --no-wipe） | — |
| 回改段 | ①查证起草 | 总控（转角色） | 人确认后加载 `feedback/SKILL.md` 转入回改①：codeqa 逐题查真实字段解法＋宽表存在性核对，新建 `rounds/<轮>/feedback.md` | **G2 进入回改**：人看过轮报、明示"进入回改"才动 |
| 回改段 | ②审定 | 人 | — | **G3**：总控只呈现回改单，等人逐行审定 |
| 回改段 | ③施工 | 人 | — | **G4**：语义层 diff 由人施工（含 cube 侧词典记忆清理）；总控绝不代改 |
| 回改段 | ④复验 | 系统 | `uv run python bin/round.py --retest <上轮>`（产物自动落 `retest-rounds/round-<上轮>-r<K>`，不占轮号；清记忆→datus KB 重投影→重启两服务→原题重跑到轮报） | **G5 放行**：见三，不可逆单列 |
| 回改段 | ⑤闭环 | 人 | 复验通过且人确认后，人把 feedback.md 行状态改"闭环" | **G6**：总控受命后才做闭环同步（见三） |

行状态机贯穿：待查证→草案→已审定→已施工→闭环（终态另有剔除）。复验挂→回③；口径错→回①；总控据此重入对应环节，闸口照停。

## 三、不可逆动作与收尾（单列，禁止混入普通步骤）

**④复验清 datus chat memory（全量清空，不可逆，不做备份——2026-10-26 用户拍板）：**
- 前置校验：上轮 feedback.md 复验集各行均为"已施工"或"剔除"；`--retest <上轮>` 形如 round-NN 且指向 `rounds/` 下已有轮（产物目录自动命名，不需要也不接受 `--round`）。
- 放行条件（G5）：人明示"跑复验"。人未发话，总控不得执行。
- 回退手段：**无**（清空即失）。唯一缓冲：复验写入 `retest-rounds/` 复验轮目录，旧轮记录不动（术语"复验轮"见 docs/glossary.md）。

**重出题库（删/换 questions.jsonl，不可逆）：**
- 背景：round.py 遇已存在题库一律跳过沿用（`bin/round.py`「题库已存在，跳过」）；换题必先移走旧题库。
- 前置校验：人明示"重出/换题"；旧题库属本轮（历史轮题库不在此列）。
- 放行条件：人明示后，先把旧题库改名备份（`questions.jsonl`→`questions.bak.jsonl`）再触发重跑；禁止不备份直接删。
- 回退手段：备份在，可还原；无备份删除=不可逆。

**闭环同步（⑤收尾，受命执行）：**
- 人置闭环后，把 `conf/metrics.json` 本轮新已审定条目顺延编号转录 `syllabus/business.md` 第八章；同步完成才算闭环。禁止只在课本侧改口径。

## 四、行为边界（红线）

1. **不自动回改（D6）**：系统段止于轮报；语义层是生产资产，agent 自动改等于绕过工程评审——总控不写 datus dosi YAML、不写 cube schema/词典，只并列证据。
2. **不代拍口径**：口径取舍是业务决策；总控在裁决书、回改单里只能并列双方证据与修正建议，落槌永远是人。
3. **引用不内联**：本契约与总控对话不复制题目原文、答案、口径定义；一切内容以 `rounds/`、`syllabus/`、`conf/metrics.json` 文件为准。
4. **环境边界**：`uv run` 只在本仓用；datus 仓 `.venv` 归 WSL 所有，Windows 侧永不对该仓跑 uv；datus 日志时间戳为 UTC（比本地慢 8 小时），涉日志取证先自校准。
5. **汇报纪律**：按根 CLAUDE.md 输出纪律——结论先行→证据→遗留；术语只用 `docs/glossary.md` 已登记词，新词先登记再使用。

## 五、总控自查（每次交话前）

1. 本步是否撞闸口？撞了是否已停下，并说清"等人决定什么、看哪些文件"？
2. 命令是否逐字按上表？退出码非 0 是否如实转述、未粉饰？
3. 是否未改任何语义层文件、未替人置任何行状态？
4. 若执行了 `--retest`：G5 放行是否有人的明示？前置校验两条是否都过？
5. 若涉及重出题库：是否有人的明示？旧题库是否已先改名备份？
