## 一、资金环节总览

### B01 · 资金主链

一笔非税资金的生命线：执收单位开具**缴款通知书**（缴款依据，一单可含多个收费项目）→ 缴款人缴款（直缴/汇缴，见 B05）→ 资金到账代理银行账户 → **清分**（按分层比例确定资金归哪个区划，见 B14）→ 缴入**国库**或**财政专户**（按资金性质落地，见 B06）→ 对账 → **财政记账**（收入正式入账）。

```text
执收单位开具缴款通知书
   ↓ 缴款（直缴 / 汇缴）
资金到账
   ↓ 清分（确定区划归属，中央/省/市/县分层分成）
   ↓ 缴入国库 / 财政专户
对账 → 财政记账
```

退付是反向环节：已缴入的资金按程序退回缴款人（见 B25）。

### B02 · 两本业务台账

资金环节的业务事实记在两本台账上，出题先分清问的是哪一本：

| 台账 | 记什么 | 粒度 |
|---|---|---|
| **收缴台账（缴款书）** | 缴款通知书从开具到缴款、资金到账、对账的**过程**事实 | 一张缴款书一单，单下一行一个收费项目 |
| **收入台账（收入明细）** | 资金形成收入的**会计**事实：清分归属、资金落地、记账 | 一笔收入一行 |

两本台账靠**缴款码**衔接：一张缴款书收到的资金，形成收入台账中的收入记录。"某缴款码是否已形成收入"即跨台账核查场景（B26）。

## 二、组织与分类

### B03 · 组织层级

一个区划下有多个**主管部门**；一个主管部门下有多个**执收单位**（收入单位）；一个执收单位可执收多个**收费项目**。主管部门是执收单位的上级归口，可按执收单位向上归口统计到主管部门。

### B04 · 收入分类链

**资金性质 > 预算科目 > 收费项目**。每个收费项目唯一对应一个预算科目、一种资金性质、一个收入类别——确定收费项目即确定其上层分类。

### B05 · 两种缴款方式（业务类型）

- **直缴**：缴款人持缴款通知书直接到代理银行缴款，资金经银行汇入财政账户。
- **汇缴**：执收单位先收款，定期开具汇缴通知书，把已收的钱汇总划转到国库或财政专户。

两方式在台账中记为**业务类型**维度（直缴/汇缴），是收缴侧最常用的分项维度。

### B06 · 资金性质与资金落地

资金性质决定资金最终落到哪个账户：

| 资金性质 | 资金落地 |
|---|---|
| 一般公共预算收入、政府性基金预算收入、国有资本经营预算收入（同属纳入预算管理资金） | **国库资金** |
| 社会保险基金预算资金（同属纳入预算管理资金） | **专户资金** |
| 财政专户管理资金（典型：教育收费，如高中以上学费） | **专户资金** |
| 代收资金、代管资金、其他 | 按业务另行归集 |

### B07 · 收入类别

收入台账按**收入类别**分类，取值包括：政府性基金收入、专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入、其他收入、代收资金、代管资金等。

### B08 · 角色与易混单位

- **缴款人**：依法负有缴纳非税收入义务的单位或个人，资金源头。注意：直缴场景票面缴款人是外部单位/个人；汇缴场景票面缴款人是执收单位自己——按"缴款人"设问需先想清直缴还是汇缴。
- **执收单位**：依法征收收取非税收入的单位，业务起点。
- **收入单位（记账单位）**：收入台账上承担记账的单位。
- **预算单位**：纳入部门预算管理、独立编制执行预算的单位。
- **执收单位 ≠ 预算单位**：两者划分维度不同（是否收非税 vs 是否入部门预算），有交集（如公立学校既收学费又吃拨款）、非子集、非互斥，是两个独立维度。

## 三、收缴侧要素（缴款书）

### B09 · 缴款书主单要素

一张缴款书一行：

| 要素 | 说明 |
|---|---|
| 缴款码 | 缴款书业务编号，贯穿收缴与收入两本台账 |
| 业务类型 | 直缴 / 汇缴（B05） |
| 执收区划、执收单位 | 谁开的单、在哪个区划执收 |
| 开票人、开票日期 | 谁开具、何时开具 |
| 金额合计（票面金额） | 整张缴款书的票面总额 |
| 缴款书有效期 | 缴款截止时点，过期不能再缴 |
| 缴款日期、缴款渠道 | 何时缴、经什么渠道缴（未缴款时缴款日期为空） |
| 资金到账日期、资金是否到账 | 资金实际到达的时点与到账标志 |
| 资金是否对账、资金对账日期 | 到账资金与账目核对完成的标志与时点 |

### B10 · 缴款书项目明细要素

一张缴款书多行，一行一个收费项目：

| 要素 | 说明 |
|---|---|
| 收费项目、收费标准 | 收的什么费、按什么标准 |
| 执收数量、执收金额（项目金额） | 该行数量与金额 |
| 资金性质、收入科目 | 该行资金的分类归属（B04/B06） |
| 是否清分、清分日期 | 该行资金是否已确定区划归属、何时清分 |
| 可退金额 | 该行尚可退付的金额 |

### B11 · 缴款书生命周期与欠缴判定

生命周期：**开具 → 缴款 → 资金到账 → 资金对账**。可能的中断状态：未缴款（有开票无缴款）、过期（有效期已过仍未缴）、作废。

**欠缴（未缴款/待缴款）判定口径**——以下条件同时满足才计入当期欠缴：

1. 开票日期在本期范围；
2. 执收单位为本单位（单位视角时限定）；
3. 未缴款（缴款日期为空，或缴款状态为未缴款）；
4. 缴款书仍有效（有效期未过系统当前日期）且未作废。

### B12 · 缴款书统计口径：笔数、票面金额、项目金额

- **笔数**：按缴款书整单计数；
- **票面金额**：按整张缴款书统计，取主单"金额合计"；
- **项目金额**：按收费项目统计，取明细行"执收金额"。

按项目分项时用项目金额，按整单统计时用票面金额。**两口径不可混加**：一张多项目的缴款书，票面金额等于各项目金额之和，整单口径只计一次。

## 四、收入侧要素（收入明细）

### B13 · 收入台账要素

一笔收入一行：

| 要素 | 说明 |
|---|---|
| 收入日期（到账日期） | 资金到账形成收入的日期——收入统计的默认时间锚 |
| 记账日期 | 收入落账（财政记账）的日期——记账进度专用 |
| 执收区划、收入区划 | 谁执收（钱从哪收的）/ 清分给哪个区划（B14） |
| 执收单位、收入单位（记账单位） | 谁执收 / 谁记账 |
| 预算单位 | 该笔收入对应的预算单位 |
| 收费项目、预算科目（收入科目）、收入类别、资金性质 | 收入分类链（B04/B06/B07） |
| 缴款日期、缴款码、业务类型 | 对应的缴款事实与直缴/汇缴方式 |
| 项目收入金额 | 该笔收入金额（对应缴款书项目金额） |
| 项目收入金额（本级） | 按 B16 口径计算的本级收入金额 |

### B14 · 双区划与双单位（区划间分成）

收入台账同时记两套区划/单位，含义不同：

- **执收区划 / 执收单位**：钱是谁收的；
- **收入区划 / 收入单位（记账单位）**：钱清分给谁。

区划间分成有两个方向，条件正好相反：

- **其他区划分入本区划**：收入区划=本区划 且 执收区划≠本区划（别处执收、分给了我）——按执收区划分项看钱从哪来；
- **本区划分到其他区划**：执收区划=本区划 且 收入区划≠本区划（我执收、分给了别处）——按收入区划统计钱到哪去。

### B15 · 收入数据来源分类

收入台账的记录按**数据来源**分为：缴款本级收入、清分收入、国库收入、清分待支出、退付收入（线下人工归档，含两个子类）等。统计"本级收入"金额时只能使用与口径匹配的来源（见 B16），不能对全表直接求和。

### B16 · "本级收入"金额三口径

收入金额按资金落地分三个统计口径，各自圈定数据来源：

- **国库资金收入**：取"国库收入"来源；
- **专户资金收入**：取"缴款本级收入" + "清分收入"两类来源；
- **退付收入**：退付类来源（线下人工归档）单列统计，不与上两项混算。

### B17 · 时间锚体系

不同问题用不同时间锚，选错锚即口径错：

| 时间锚 | 含义 | 什么时候用 |
|---|---|---|
| 开票日期 | 缴款书开具 | 欠缴统计（欠的是"本期开的单"） |
| 缴款日期 | 缴款人完成缴款 | 收缴进度、收缴金额 |
| 资金到账日期 / 资金对账日期 | 资金到达 / 对账完成 | 到账、对账环节 |
| 收入日期（到账日期） | 形成收入 | 收入统计默认锚 |
| 记账日期 | 财政记账 | 记账进度 |

## 五、应用场景（问题骨架）

### 5.1 财政用户 · 收入侧

### B18 · 各单位收入情况

本月各单位收入：时间锚收入日期=本月，按**收入单位**汇总收入金额；可按"收入单位+收费项目"、"收入单位+预算科目"、"收入单位+收入类别"分项。

### B19 · 分维度收入构成（科目/项目/资金性质/收入类别）

给定时间范围（收入日期），分别按**预算科目**、**收费项目**、**资金性质**、**收入类别**分项汇总收入金额，每个维度都可再交叉收入区划/收入单位/预算单位。例：某预算单位本月各科目收入（时间=本月，预算单位=指定单位，按科目分项）。

### B20 · 各级区划收入

给定时间范围（收入日期），按**收入区划**分项汇总收入金额；可交叉主管部门、收入单位、资金性质、预算科目、收费项目做单维或多维。

### B21 · 区划间分成（场景）

B14 两个方向的问题化：其他区划分入本区划的收入、本区划分到其他区划的收入。两方向过滤条件相反，题面必须说清方向。

### B22 · 记账进度

本区划已完成记账的收入：时间范围用**记账日期**（不是收入日期），条件收入区划=本区划；可按记账日期、执收单位分项统计收入金额。

### 5.2 单位用户 · 收入侧

### B23 · 本单位分入收入

执收单位=本单位视角下的三问：

- **分入本级国库收入**：收入区划=本区划，且资金性质属国库类三项（B06），可按资金性质分项；
- **分入本级专户收入**：收入区划=本区划，且资金性质属专户类两项（B06），可按资金性质分项；
- **分入各级区划收入**：不限区划，按收入区划分项。

### B24 · 单位间分成（场景）

- **其他单位分入本单位**：收入单位=本单位 且 执收单位≠本单位，按执收单位分项；
- **本单位分入其他单位**：执收单位=本单位 且 收入单位≠本单位，按收入单位分项；
- **本单位执收金额分入各级区划**：执收单位=本单位，按收入区划统计。

### B25 · 退付

本单位退付金额：收入单位=本单位，来源为退付类（B16）；可按预算科目、收费项目分项统计退付金额。

### B26 · 收入核查

- **某缴款码是否已形成收入**：按缴款码到收入台账查存在性；
- **某月份之前收缴的收入**：例"缴款日期在 6 月之前"的收入金额，时间条件落在缴款日期上。

### 5.3 收缴侧

### B27 · 征收进度同比（财政）

按月份同比今年与去年每月收缴金额，时间锚=**缴款日期**，统计**票面金额**；可按执收区划、主管部门、执收单位、资金性质、预算科目、收费项目做单维或多维。

### B28 · 年度收缴笔数（单位）

缴款日期在本年范围 且 执收单位=本单位，统计缴款书**笔数**；可按业务类型（直缴/汇缴）分项。

### B29 · 年度欠缴（单位）

按 B11 欠缴四条件（开票日期在本年、执收单位=本单位、未缴款、有效未作废），统计缴款书**笔数和票面金额**；可按业务类型（直缴/汇缴）分项。

## 七、出题红线（易错口径）

2. 记账进度按记账日期，收入统计默认按收入日期，两锚不可互换（B17/B22）。

8. 笔数按缴款码去重计数，台账行数不等于笔数（B30/B36）。

### B30 · 统计通用拍板（round-02）

适用于本章各指标的通用规则：

- **笔数键**：笔数一律按缴款码去重计数——台账一行不等于一笔，同一缴款码的多个记录行只算一笔（内部行号与缴款码不一一对应）。
- **时间锚**：缴款类统计以**缴款日期**为锚，入库类统计以**入库日期**为锚，精度到日。
- **金额分档**：按单笔金额分 10 倍档：<1千、1千–1万、1万–10万、10万–100万、≥100万。
- **时长分档**：<1天、1–10天、10–100天、≥100天。

### B31 · 缴款金额

缴款侧金额总指标：缴款资金的金额，时间锚=缴款日期；可按月份、缴款人（付款方）、缴款方式（直缴/汇缴）分项。单位：元。（登记表：缴款金额，round-02 已审定）

### B32 · 缴库金额

**已缴入国库**的资金金额。"已缴入国库"以入库标志单一定义判定，另一资金状态标志不参与该判定；时间锚=入库日期；无维度分解。单位：元。指标正名=缴库金额，曾用名"已缴入国库金额"。（登记表：缴库金额，round-02 已审定）

### B33 · 代收非税收入金额

代理银行代收的非税收入金额；时间锚=缴款日期；按代理银行分项。单位：元。（登记表：代收非税收入金额，round-02 已审定）

### B34 · 执收单位经手收入金额

执收单位视角经手的收入金额；时间锚=缴款日期；按执收单位分项。单位：元。（登记表：执收单位经手收入金额，round-02 已审定）

### B35 · 待划拨金额

已清分、**尚未划拨**的资金金额，以划拨标志判定；时间锚=清分日期；按收入项目分项。单位：元。别名"未划拨金额"。（登记表：待划拨金额，round-02 已审定）

### B36 · 完成笔数

**完成缴款**的缴款书笔数，以"完成缴款"标志判定（不另立到账时间锚）；笔数按缴款码去重（B30）；时间锚=缴款日期；可按缴款方式（直缴/汇缴）分项。单位：笔。（登记表：完成笔数，round-02 已审定）

### B37 · 未缴笔数

**已开具且未缴款**的缴款书笔数：缴款状态为未缴款且非作废，并以"有开票、无任何缴款记录"兜底（防状态未回写）；时间锚=开票日期，未缴时长=开具日至今（未缴款无缴款日期可减），可按时长分档（B30）。单位：笔。（登记表：未缴笔数，round-02 已审定）

### B38 · 在途滞留金额

划拨指令已发出、资金**尚未到账**的在途资金金额，属**存量池口径**：不带年度窗口，在途池不能按年度过滤（按指令时间过滤会清空在途池，属数据现实）。辅指标=在途笔数，按划拨单号计数（不适用缴款码笔数键）。时间锚=划拨指令下达日。单位：元。（登记表：在途滞留金额，round-02 已审定；双侧池基线对齐细节见登记表）

### B39 · 对账/记账异常核查（命中笔数）

资金状态矛盾的两类异常存在性核查，统计笔数并列出单号明细，无时间锚；可按异常类型分项：

- **对账层异常**：对账成功，但资金未入库；
- **记账层异常**：收入已记账，但资金未入库。

单位：笔。（登记表：命中笔数，round-02 已审定）
