## 一、业务总览

### B01 业务概述

非税收入收缴业务，描述一笔非税资金从**执收单位发起缴款通知书**开始，经缴款人缴款、代理银行代收，到**清分归属、汇总划拨、缴入国库、完成对账与财政记账**的全过程。

- **资金流**与**票据流**并行：钱从缴款人流向国库，财政电子票据随缴款开具。
- 参与方：**缴款人、执收单位、代理银行、财政**四方。

## 二、业务角色

### B02 非税收入业务角色

| 角色 | 核心职能 | 资金流向中的位置 |
| :--- | :--- | :--- |
| **缴款人** | 依照法律、行政法规或部门规章规定，负有缴纳非税收入义务的单位和个人（典型场景：个人办护照缴费） | 资金源头 |
| **执收单位** | 依法征收或收取政府非税收入的单位，包括行政机关、事业单位、代行政府职能的社会团体等；业务起点，负责发起缴款通知书 | 业务发起 |
| **预算单位** | 纳入部门预算管理、独立编制并执行预算的行政事业单位；主要经费来源为财政拨款，也可能有其他收入 | 管理主体（非资金流向角色） |
| **代理银行** | 是指与财政部门签订委托代理协议、代理政府非税收入收缴业务的商业银行。财政部门在代理银行开设的账户主要有两种形式：待结算财政款项科目（用于核算反映非税收入款项的收纳和清算）和非税收入财政专户 | 收款端 |
| **财政专户** | 是财政部门在代理银行开设的专用存款账户，用于接受从财政汇缴专户划入和缴款人直接缴入的政府非税收入以及政府非税收入的分成、划解、退付。 |  |
| **财政汇缴专户** | 是财政部门为执收单位在代理银行开设的用于非税收入收缴、与财政专户进行清算的专用存款账户，原则上实行日终零余额管理。 |  |
| **待解缴科目** | 是由代理银行设立，用于执收单位非税收入的收入收缴，以及与财政专户进行清算的银行科目账户，当日清算为零。 |  |
| **清算银行** | 负责对公共支付平台支付渠道划转的非税收入款项进行归集、匹配核对和汇划清算的银行业金融机构 | 中间归集 |
| **国库（国库代理行）** | 接收资金入库，核算入库/退库/更正；按规定在"待结算财政款项"科目下设立非税收入收缴清算账户 | 终点 |
| **财政** | 确定资金归属（清分）、划拨监督、缴库、对账、财政记账、对欠缴款项催缴 | 管理与监督 |

### B03 系统用户角色

本财政系统分两类用户角色：**财政用户**（财政侧：清分、划拨、缴库、记账、催缴）与**单位用户**（执收单位侧：开单、缴款、汇缴）。

## 三、易混辨析

### B04 执收单位 vs 预算单位（易混概念）

两者按不同维度划分：执收单位看的是**"是否收非税收入"**，预算单位看的是**"是否纳入部门预算管理"**。

- **交集**：公立学校既接收财政拨款（预算单位属性），又收取学费（执收单位属性）。
- **不是子集**：存在不收非税收入的预算单位（纯财政拨款），也存在不属于预算单位的执收情形（如代行政府职能的社会团体）。
- **不是互斥**：同一个单位可以同时具备双重身份。

### B05 缴款通知书 vs 汇缴通知书（易混概念）

两个"通知书"名字相近，但**方向完全相反：一个往里收钱，一个往外划钱**。

- **缴款通知书**：执收单位开给**缴款人**的，通知缴款人向指定账户缴款。票面上缴款人是外部单位或个人，执收单位是开单方。资金方向：缴款人 → 指定账户（代理银行）。例如浙江的电子缴款通知书，执收单位是市场监管局，缴款人是被处罚的企业或个人。
- **汇缴通知书**：核心功能是执收单位把**已经收上来的钱**汇总后，开给**银行 / 财政**的**划款指令**。它的"缴款人"在制度设计上就是执收单位自己（或财政汇缴专户）。资金方向：单位账户 → 国库 / 财政专户。

与两种缴款方式对应：**直缴**场景用缴款通知书（通知缴款人去缴款）；**汇缴**场景用汇缴通知书（单位把已收的钱汇总后划转）。

### B06 直缴（直接缴款、直接缴库）

缴款人持缴款通知书到代理银行缴款，银行代收后资金汇入过渡户，再行缴库。（财政非税收入的一种收缴方式，缴款人按照有关规定，直接将应缴款项缴入财政汇缴专户、财政专户或国库单一账户。）

### B07 汇缴（集中汇缴）

执收单位先收款，**定期**开具汇缴通知书汇总上缴，资金从单位账户划转到国库或财政专户。（财政非税收入的一种收缴方式，由执收单位按有关规定，将所收的应缴款项按收入项目汇总缴入财政汇缴专户或财政专户。）

### B08 票据作废（票据异常处理）

财政票据开具**当月**，缴款人未完成缴款或业务未记账，票据全部联次可收回，在发票各联注明"作废"字样，纸质发票可操作。**电子票据不适用作废，只能冲红。**

### B09 票据冲红（票据异常处理）

**跨月**、对方已认证/记账（记账周期已过）、或数电发票（无论当月与否，不可作废，只能冲红）时，开具**红字发票（负数发票）**进行冲减，无需追回原纸质发票。

> 关于"下个周期冲掉"的理解：财务记账中，红字发票的开具和入账通常发生在**下一个会计期间**（或当期内调整），作用是冲减**开票当期**的销售收入或进项税额。

## 四、资金主链

### B10 资金主链总览

```text
执收单位发起缴款通知书（缴款依据，项目明细随单逐项列明）
   ↓ 缴款（直缴 / 汇缴两条路）
   │    ← 欠缴时：财政催缴（定期），促执收单位汇缴上缴
银行代收
   ↓
① 清分 —— 收缴款分给什么区划，按分层比例确定中央/省/市/县归属
② 汇总 —— 按单位、科目汇总，形成待划拨批次
③ 划拨 —— 资金拨付指令与银行划转
④ 缴库 —— 资金进入国库
⑤ 对账（国库）、财政记账
```

### B11 清分

收缴款分给什么区划，按分层比例确定**中央/省/市/县**归属。

### B12 汇总

按单位、科目汇总，形成待划拨批次。

### B13 划拨

资金拨付指令与银行划转。

### B14 缴库

资金进入国库。

### B15 对账与财政记账

对账（国库）、财政记账。

### B16 欠缴与催缴

欠缴时：财政催缴（定期），促执收单位汇缴上缴。

## 五、票据流（并行）

### B17 财政电子票据

缴款完成后开具**财政电子票据**（票种、号码），票据与缴款书同源关联；票据生命周期还包含**作废、冲红**等异常处理（解释见 B08/B09）。

## 六、业务口径提示（出题重点）

### B18 缴款人口径

缴款通知书票面缴款人 = 外部单位或个人；汇缴通知书票面缴款人 = 执收单位自己（或财政汇缴专户）。按"缴款人"统计时两表口径不同，**不能混用**。

### B19 执收单位 ≠ 预算单位

交集但非子集、非互斥，作为维度/属性时是**两个独立概念**（辨析详见 B04）。

### B20 金额统计口径

缴款通知书票面载明缴款人与总金额等头信息，征收项目与对应金额**逐项列明**。统计一笔缴款的金额，应以**征收项目的金额明细**为准，而非通知书票面上的总金额。

### B21 作废 / 冲红口径

作废票对应缴款未完成或未记账，**不应计入收入**；冲红以红字（负数）发票冲减，红字入账通常在下一会计期间——按期间统计收入时注意**冲减的归属期**（名词详见 B08/B09）。
