# 术语表（glossary）

> 规则（CLAUDE.md【术语纪律】）：新术语先登记本表再使用；每条 ≤2 句，"是什么 + 在本项目指什么"。

- **payload（原始报文）**：程序运行时逐条输出的原始消息流，一字不改存档，是一级证据。本项目指 datus 每答一题的完整 agent 循环输出，现有 25 份存于 datus 仓 `tmp/qa_run/`（M0 迁入本仓 `fixtures/v0/qa_run/`）。
- **fixture（测试基准数据）**：一组固定输入 + 已知正确答案，用于反复验证代码没被改坏。本项目=`fixtures/v0/`：25 份 payload 作输入，`qa_results.json` 作标准答案（M0 建立）。
- **回归门**：每次改动提取逻辑后必须重跑的基准比对，全绿才允许合入。本项目的门=对新提取器重放 25 份 fixture，与标准答案逐字段 diff。
- **投影表**：新旧两种数据格式之间的字段对照表。本项目用于把新作答卡字段映射回 `qa_results.json` 的字段做逐字段比对。
- **豁免字段**：比对时明确跳过的字段，须记录原因。本项目例：`elapsed_s`（计时不在留痕里，无法恢复）、`desc`（展示拼接串，非数据）。
- **幂等**：同一操作重复执行，结果不变、无副作用。本项目指适配器支持 `--only qNN` 子集复跑且不污染已有留痕。
- **headless（无头）**：无交互界面的命令行调用方式。本项目用：`datus -p`、`claude -p`、`POST :4100/chat`。
- **盲考**：出题人不读答题人能力卡、不读历史题库，只读考纲出题（决策 D3b）。
- **三态**：cube `POST :4100/chat` 返回的三种类型：`answer`（有答案）/ `ask`（反问口径）/ `nomatch`（能力外）。
- **作答卡**：每题每方的机器提取结果（统一结构），从原始留痕提取而来。M0 最小结构 11 字段，M1 升格为 JSON Schema。
- **语义层**：智能体把自然语言映射到 SQL 所依赖的建模层。datus 侧=dosi YAML（`fne_fund_main.yml`），cube 侧=Cube schema + 词典。
- **对接**：把本仓适配器与真实智能体服务连起来调通，完成一次"问→答→留痕→提取"端到端。本项目 M0 的主目标：datus 与 cube 各自证明"可调用、能答数"。
- **活体验证**：真实调用正在运行的智能体服务来做验证。与重放相对——本项目指新题真打 `datus -p` / `:4100/chat`，不是比历史存档文件。
- **重放**：拿历史存档数据喂给新代码再跑一遍，比对结果。本项目两种：datus 25 份 payload 喂提取器（离线，不打 datus）；cube 30 题重新调用活服务（在线）。
